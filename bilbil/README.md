# 哔哩哔哩视频统计助手

这是一个基于Python和PyQt5开发的哔哩哔哩视频统计工具，可以根据用户指定的关键词和时间范围，搜索并展示相关视频的基本信息和统计数据。

## 功能特点

- 关键词搜索：根据输入的关键词搜索相关视频
- 时间范围筛选：可以选择特定的时间范围
- 排序功能：支持按发布时间、播放量、弹幕数、收藏数、硬币数和点赞数排序
- 详细展示：以表格形式展示视频的标题、UP主、发布时间、播放量等信息

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

运行以下命令启动应用：

```bash
python bilibili_stats.py
```

## 注意事项

- 当前版本使用模拟数据进行展示，实际使用时需要替换为真实的B站API调用
- B站API可能有调用限制，请合理使用
